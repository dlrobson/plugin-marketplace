# plugin-dev

Tools for developing Claude Code plugins — skills, agents, commands, hooks, and MCP integrations.

## What's included

**Skills** — reference guides invoked during development:
- `agent-development` — building Claude Code agents
- `command-development` — building slash commands
- `hook-development` — building hooks
- `mcp-integration` — integrating MCP servers
- `plugin-settings` — configuring plugin settings
- `plugin-structure` — plugin directory layout and conventions
- `skill-development` — writing and organizing skills

**Agents** — specialized sub-agents:
- `agent-creator` — scaffolds new agents
- `plugin-validator` — validates plugin structure and correctness
- `skill-reviewer` — reviews skill quality

**Commands** — slash commands:
- `/create-plugin` — guided end-to-end plugin creation workflow

## Installation

```bash
claude plugin install plugin-dev@dlrobson-plugins
```
